# 高事实风险清单 · 通用防幻觉基础指令（不绑定具体领域）

适用：A 类请求（书籍/文献/名人著作/法条/史实名录等具名清单）。

1. **可查证优先**：清单条目优先使用可查证的知名内容；不要为凑齐数量自行创造人名、书名、著作、数据或出处。
2. **无法确认则舍弃**：无法确认名称、作者/归属匹配关系时，舍弃本条，禁止臆造；宁可条目少于用户目标 N，也不可注水。
3. **简介贴合主体**：介绍描述须贴合该条目真实内容；禁止脑补从未核实的情节、评价、数据或「伪权威」出处。
4. **材料边界**：有检索/书目核验 Observation 时，优先从材料中组织条目；禁止脱离材料自由扩充冷门具体条目。
5. **诚实声明**：材料不足时文首标明「未充分联网核实」，并说明未能凑满目标条数的原因。
